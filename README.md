# URLScra

**Paste URL. Get Data.**

Windows desktop app untuk mengekstrak data web seperti harga, gambar, video, pautan dan mengeksport hasil ke CSV.

## Status

Project bootstrap. Development milestones akan dibina melalui branch berasingan sebelum digabungkan ke `main`.

# Security Policy

## Reporting a vulnerability

Please **do not disclose suspected security vulnerabilities publicly** in issues, discussions, pull requests, or other public channels.

Report the matter privately to the repository owner through the owner's GitHub contact channel and include, where possible:

- affected version or commit;
- a concise description of the issue;
- reproducible steps;
- potential impact;
- suggested mitigation, if known.

Please avoid publishing proof-of-concept exploit code or sensitive technical details before the repository owner has had a reasonable opportunity to investigate and address the issue.

## Scope

Security reports are welcomed for URLScra itself. This policy does not grant permission to access third-party systems, bypass authorization controls, perform destructive testing, exfiltrate data, or violate applicable law.
